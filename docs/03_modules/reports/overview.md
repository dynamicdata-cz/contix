# Zpráva pro vedení a exporty

## Zpráva pro vedení (`/management`)

Jedna stránka se semaforem pro jednání vedení za zvolené období (výchozí posledních 12 měsíců), za jednu společnost:

| Ukazatel | Zelená | Oranžová | Červená |
|---|---|---|---|
| Míra shody (rámec dle režimu) | ≥ 80 % | ≥ 50 % | < 50 % |
| Rizika nad hranicí akceptovatelnosti | 0 | > 0, všechna mají zvládání | některé bez rozhodnutí o zvládání |
| Akce plánu zvládání po termínu | 0 | 1–4 | ≥ 5 |
| Incidenty v období | žádný významný | významný incident | zmeškané hlášení |
| Zjištění auditů po termínu | 0 | 1–2 | ≥ 3 |
| Otestovaná zavedená opatření (12 m.) | ≥ 70 % | ≥ 30 % | < 30 % |
| Aktiva v červeném stavu | 0 | 1–4 | ≥ 5 |
| Plány kontinuity bez platného testu | 0 | 1–2 | ≥ 3 |
| Povinnosti po termínu | 0 | 1–9 | ≥ 10 |

Výstupy: obrazovka, **Tisk / PDF**, **Word**. Zpráva se neukládá – formální záznam je zpráva o přezkoumání ISMS.

## Word u dokumentů ISMS

U každého dokumentu (SoA, zpráva o hodnocení rizik, plán zvládání, zpráva o přezkoumání) je tlačítko **Word** –
pro náhled aktuálního stavu i pro uloženou / schválenou verzi. Široké dokumenty jsou na šířku. Viz
[ADR-018](../../05_decisions/ADR-018-reports-word-export.md).
